## Quick Start Commands (Windows cmd.exe)

### Development Mode
```cmd
# Terminal 1: Start backend (serves API at http://localhost:8080)
npm run dev

# Terminal 2: Start frontend dev server (http://localhost:5173)
cd frontend
npm run dev
```

Then visit: **http://localhost:5173/**
- Upload form proxies to http://localhost:8080/api/jobs
- Vite HMR enabled for live reload

### Production Mode
```cmd
# Build frontend to frontend/dist/
cd frontend
npm run build

# Return to root and build backend
cd ..
npm run build

# Start server (serves frontend from http://localhost:8080)
npm start
```

Then visit: **http://localhost:8080/**
- Frontend served as static assets
- API available at /api/*

### Run Smoke Test
```cmd
cd frontend

# Install ts-node (already done)
npm install ts-node --save-dev

# Run test
npm run test:smoke
```

Expected output:
```

✓ Step 2: Creating test file...
✓ Step 3: Uploading file...
✓ Step 4: Verifying job creation...
✓ Test file cleaned up
✅ Smoke test passed!
```

## Notes & Important Details

1. **Redis Connection Error**: The backend tries to connect to Redis on startup but continues if it fails. This is normal in dev mode without Docker. To avoid the error, either:
   - Start Redis: `docker run -d -p 6379:6379 redis`
   - Update `.env` to point to a running Redis instance
   - The API still works for upload/status without Redis (queue functionality disabled)

2. **Database**: The API connects to PostgreSQL. Make sure your `.env` has `DATABASE_URL` configured. Without it, job creation will fail at the DB insert step.

3. **Frontend Environment**: The frontend doesn't need environment variables for dev (Vite proxy handles /api routing). For production, the backend serves it.

4. **Static Assets**: The production frontend build (`npm run build`) creates:
   - `frontend/dist/index.html` — Main page
   - `frontend/dist/assets/index-*.js` — React bundle
   - `frontend/dist/assets/index-*.css` — Styles

5. **SPA Routing**: All non-API routes serve `index.html`, so you can add client-side routing later (React Router, etc.)
